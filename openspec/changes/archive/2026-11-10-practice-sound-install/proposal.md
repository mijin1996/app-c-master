# 코드 실습 · 전자 피아노 효과음 · 홈 화면 안내 · 실제 서버 API 고침

## 왜
- 객체지향 "코드로 보면" 예시를 읽기만 하지 말고 비슷한 코드를 직접 풀어 보고 싶다.
- 정답 · 오답 효과음을 전자 피아노처럼 부드럽게.
- 휴대폰에서 앱처럼 쓰는 법을 들어올 때 안내하고 싶다 (Vue Bits Scroll Stack 느낌).
- 실제 서버(app-c-master.itsjinmi.workers.dev)에서 로그인이 안 됐다: Worker 배포라 functions/ 가 실행되지 않아 /api 가 404.

## 무엇을
1. 레슨마다 코드 실습 2문제(빈칸 채우기 1 + 결과 맞히기 1, 총 26). 문제당 +5 XP, 서버가 다시 계산. 힌트, 두 번 틀리면 정답 보기.
2. tools/sound-synth.mjs: FM 합성 전자 피아노 wav (정답: 도-미-솔 상행, 오답: 낮은 두 음 하행).
3. 들어올 때마다 "앱처럼 쓰기" 안내창 (내 기기 카드가 맨 앞, 스크롤하면 카드가 쌓임). ✕ · 바깥 · Esc 로 닫고, 이번 방문에서는 다시 안 뜸. 홈 화면 앱으로 열면 안 뜸. manifest + 코디 아이콘.
4. server/worker.js + wrangler.jsonc: /api/** 를 functions 처리기로 안내, D1 c-master-db 연결.
5. 객체지향 메뉴(Option Wheel 모양)는 사용자 요청으로 바꾸지 않음.
