# 제안: code.ai 이름, 첫 화면 워드마크, 알고리즘 단계

## 왜
- 서비스 이름을 **code.ai** 로 정했다 (캐릭터 최종 단계 이름 "C 마스터"는 그대로).
- 첫 화면에 들어오자마자 보이는 인상적인 문구가 필요하다.
- 18단원을 끝낸 학습자가 이어서 도전할 알고리즘 문제가 없다. USACO처럼 난이도 단계로 나누어 달라는 요청.

## 무엇을
- 제목 글꼴을 하다 타입 레벨업(SIL OFL 1.1, 분할 WOFF2)으로 바꾼다.
- 로그인 첫 화면 맨 위에 `code.ai` 워드마크를 테크 텍스트 효과로 보여 준다.
- 브론즈·실버·골드·플래티넘 4단계 × 4문제 = 16문제를 새로 만들고, 단계별 섹션 화면(`#algo`)을 추가한다.
