# 설계: C 마스터 웹사이트 정식 버전

브레인스토밍에서 정한 내용을 정리한 문서입니다. 요구사항은 [openspec/specs](../../../openspec/specs), 결정 이유는 [openspec 변경 기록](../../../openspec/changes/archive/2026-11-09-web-release/design.md)에 있습니다.

## 사용자와 목표
- C언어를 어려워하는 학생(중학생 포함), 그리고 반 학생 진도를 보는 선생님
- 문제 72개 + 퀴즈 90문항을 브라우저에서 바로 풀고, 어느 기기에서든 이어서 한다

## 브레인스토밍에서 정한 것
| 질문 | 결정 |
|---|---|
| 저장 위치 | Claude 계정 대신 자체 서버 (Cloudflare D1) |
| 로그인 | 아이디·비밀번호 + 복구 코드 (이메일 없음) |
| 배포 | GitHub 저장소를 Cloudflare 대시보드에서 연결 |
| AI 힌트 | 화면에서 숨기고, 나중에 API만 연결하면 켜지게 |
| 단원 잠금 | 없음 (권장 순서만) |
| 풀이 시간 | ★10·★★20·★★★30분, 넘기면 20% |
| 모범 답안 | 정답 후, 또는 시간 초과 + 직접 쓴 코드 2번 제출 후 |
| 코드 규칙 | 수업 계층 구조, K&R 중괄호, Given-When-Then |

## 화면
로그인/가입/계정 찾기 → 학습 지도(코디·레벨·스테이지) → 단원(개념·문제·퀴즈) → 문제 풀이(타임라인·에디터·채점) → 퀴즈 → 문제 목록 · 랭킹 · 내 기록 · 선생님 · 설정

## 검증 방법
- `npm test`: 도메인·Mapper·서버(실제 SQL)·엔드포인트·클라이언트 Service·72문제 모범답안
- `node tools/dev-server.mjs` 로 브라우저에서 가입부터 비밀번호 재설정, 선생님 화면까지 확인
