# c-master

## 기획
- 학습 흐름: 커리큘럼 → 개념 → 문제 → 퀴즈 → 클리어 → 캐릭터 진화
- 5개 스테이지, 난이도별 제한 시간, 클리어 조건에 따라 캐릭터가 아기 코더에서 C 마스터로 진화하도록 설계
- 랭킹은 상위 20명까지 보여 줌

## 구성
- 기술: 바닐라 JS 화면 + Cloudflare Worker(서버) + D1(DB), 채점은 브라우저 안에서
- 데이터 흐름: 요청(클라이언트가 보냄) → 응답(서버가 돌려줌) 방식
- 경험치는 서버가 다시 계산한 값을 저장하고 화면에 보여 줌

## 적용
- 문제·퀴즈 고치기 (원본 수정 → 빌드 → 테스트)
- 꺼 둔 기능 켜기 (유료 언어, AI 힌트)
- 저작권·출처 표시

> 단원 18, 스테이지 5, 문제 72, 퀴즈 90, 알고리즘 32는 실제 데이터 파일에서 센 숫자
