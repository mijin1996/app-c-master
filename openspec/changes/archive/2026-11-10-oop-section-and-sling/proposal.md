# 객체지향·설계 섹션 + 새총 버튼 효과

## 왜
- 수업에서 Java · C# 객체지향과 아키텍처(DataSource → Repository → Service, Result 패턴, SOLID, 비동기 등)를 배우고 있는데, 사이트에는 C언어 · 알고리즘 문제만 있다.
- 배운 내용이 어려워서, 초등학생도 알아들을 비유 설명과 함께 바로 풀어 보는 문제가 필요하다.
- 버튼 효과를 Vue Bits의 Sling Button 느낌(당기고 놓으면 튕겨 나가는 새총)으로 바꾸고 싶다.

## 무엇을
1. 상단 메뉴에 **객체지향** 섹션을 추가한다. 13개 레슨, 레슨마다 "쉽게 말하면" 설명 + 핵심 정리 + 5문항 퀴즈(문항마다 쉬운 해설).
2. 레슨 퀴즈 점수는 진도(`oopQuiz`)에 최고 점수로 남고, 4문항 이상 +10 XP, 만점 +10 XP. 단원 클리어 · 코디 진화에는 들어가지 않는다. 경험치는 서버가 다시 계산한다.
3. 모든 버튼 누름 효과를 도화선(Fuse)에서 새총(Sling)으로 바꾼다. 지우기의 4초 되돌리기 기능은 그대로 둔다.
4. 출처 · 라이선스 창에 Sling Button(Vue Bits, MIT + Commons Clause) 줄과 수업 교안 · 필기 출처를 적는다.
