# 제안: 화면 효과와 배포 마무리

## 왜
누를 때 반응이 느껴지고, 레벨 업이 더 기쁘게 보이길 원함. 실제 배포 전에 실패할 만한 곳을 정리.

## 무엇을
- 클릭 불꽃 (Click Spark 참고), 모든 버튼의 도화선 테두리 (Fuse Button 참고), 문제 지우기는 4초 되돌리기
- 레벨 업 때 화면 전체를 덮는 회전 글자 (Rotating Text 참고)
- 문제 풀이 창을 누르면 테두리만 초록빛으로 은은하게 빛나고, 밖을 누르면 원래대로
- `wrangler.toml` 을 예시 파일로 바꿔 대시보드 설정과 충돌하지 않게, 배포 안내와 확인 목록 정리
