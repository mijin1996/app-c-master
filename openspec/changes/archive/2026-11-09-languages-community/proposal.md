# 제안: 알고리즘 32문제, 풀이 언어 선택, 커뮤니티

## 왜
- USACO 단계별 주제를 더 넓게 다뤄 달라는 요청 (특정 문제를 옮기거나 이야기만 바꾸는 것은 저작권 위험이 있어, 주제 목록만 기준으로 새로 씀).
- 알고리즘 문제를 C 말고 다른 언어로도 풀고 싶다는 요청. 유료 언어는 나중에 결제와 함께.
- 학생들이 직접 문제를 내고 맞고 틀림을 의논하는 공간.

## 무엇을
- 단계마다 4문제 추가 (모두 8문제), Python 모범답안 32개.
- 언어: C, Python(브라우저 Pyodide, 무료), C++ · Java(Judge0 서버, 유료 준비 중 · 꺼짐).
- 커뮤니티: 문제 내기, 토론 댓글, 좋아요, 채택, 신고 자동 숨김, 선생님 숨기기, 지우기.
